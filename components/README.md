# Persistent interaction handlers

Copy `tools/templates/button.js`, `tools/templates/select-menu.js`, or `tools/templates/modal.js` here, along with their paired command files in `commands/`.

Save a `.js` or `.cjs` file and Puro loads it automatically. No central event edits are required. Nested folders and `guilds/<slug-or-id>/` scopes are supported.
